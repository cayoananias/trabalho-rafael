🐹 HamsterHouse - E-commerce Pet Prototype

✨ Visão Geral (Overview)

O HamsterHouse é um projeto protótipo de e-commerce completo, simulando uma loja virtual especializada em produtos para hamsters. Seu objetivo principal foi aplicar os conhecimentos de desenvolvimento web front-end em um cenário prático e multifuncional.

Este site não apenas exibe produtos; ele simula toda a jornada do usuário: desde o login até a visualização dos detalhes do produto, passando pela adição ao carrinho e pelo contato com o atendimento. O projeto foi construído com foco em experiência do usuário (UX) e responsividade, garantindo uma navegação impecável em qualquer dispositivo (desktop ou mobile).

📚 Funcionalidades Implementadas (Key Features)

O protótipo inclui diversas funcionalidades que demonstram o domínio das tecnologias utilizadas:

Sistema de Autenticação: Página de Login funcional, simulando a área restrita do cliente.
Catálogo de Produtos: Exibição organizada e filtrável de produtos em diferentes categorias (Básico, Premium, Acessórios).
Busca e Filtros: Implementação de barra de busca para facilitar a localização de itens específicos.
Carrinho de Compras: Simulação da adição de itens ao carrinho, com listagem dos produtos selecionados.
Página de Contato Avançada: Formulário completo que coleta diversos dados do usuário, além das FAQs (Perguntas Frequentes).
Estrutura Semântica: Utilização correta e semântica do HTML5 em todo o conteúdo da página.
Design Responsivo: Layout totalmente adaptável usando princípios de Mobile First, garantindo visualização perfeita em qualquer tela.

🛠️ Tecnologias e Linguagens Utilizadas (Technologies Used)
O desenvolvimento foi realizado utilizando os pilares do front-end, que juntas constroem a experiência interativa:

HTML5: Responsável pela estrutura semântica de todo o conteúdo, organizando cabeçalhos, navegações, cards de produtos e formulários.

CSS3: Utilizado para estilização avançada e layout visualmente atraente. Foi fundamental o uso de Flexbox e Grid Layout para construir o sistema de grades responsivo dos produtos.

JavaScript (JS): Adiciona a interatividade ao site. Ele foi usado para:
Validar formulários na página de login e contato.
Gerenciar os eventos do carrinho de compras (adiicionar/remover itens).
Manipular o DOM para carregar conteúdo dinamicamente (simulando a funcionalidade de um site real).
